## 问题与修改

1. **核查式答疑开关**：绝对定位圆点缺少左锚点，默认静态位置叠加 translate 后越出轨道。只补 `left-0`，两端均保留 2px 内距，保持原尺寸与配色。
2. **联网搜索**：真实旧 Docker worker 访问 Brave 公共搜索返回 HTTP 429；搜索 API key 和 SearXNG 均未配置，Compose 没有漏传已有密钥。Brave 抛出结构化 HTTP 状态/模式；原可选失败日志增加供应商、原因及固定配置提示，不输出查询、凭据或上游页面。不修改搜索次数和失败行为。**外部搜索尚未恢复**；稳定使用需在已有设置中配置可用搜索服务。详见 [搜索调查](2026-09-14-brave-search-rate-limit.md)。
3. **学生提问后的冗长讨论**：Legacy/Pi 均加入本次用户输入策略。普通提问最多两次发言；教师先答，非教师仅可做一次简短、有用的补充。裸确认语最多一次简短回应并结束；`对吗`、`明白了，但……` 不当作结束确认。明确要求深入讨论时最多三次。没有用户输入的课程脚本讨论保持原预算，生成的讲解 actions 不受影响。非教师同一轮不重复出场，提示词限制补充为一个短句。
4. **课程完成页**：既有 `isCourseComplete` 为真时，左侧目录按实际 scenes 展示，忽略已完成课程遗留的规划占位，保留原“小奖杯＋课程完成”入口；未完成、失败及取消时仍展示原状态。中央标题最多两行，长单词可换行，悬停可查看全文。保留奖杯、动效、统计和短屏滚动；不回写课程标题或提纲。

独立审查发现并修复了两项讨论边界：一轮确认语若模型空回复，返回空响应错误，不能假装正常结束；复用会话时，预算绑定本次不可变请求输入，避免 React ref 尚未更新时读取上一轮用户消息。老师工具调用不按工具个数占用发言预算。
