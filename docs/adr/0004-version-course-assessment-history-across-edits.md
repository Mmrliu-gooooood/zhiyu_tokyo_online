# Version course assessment history across material edits

Material changes to Scenes, Lessons, assessment coverage, or checkpoint placement will create a Course revision, and learner completion facts, Question sets, Assessment attempts, scores, and Course reports will retain the revision in which they occurred. Completing an older revision remains true; the learner instead sees that newer content is available, while new checks use the latest revision plan. This avoids silently rewriting evidence of what was learned and assessed when an editor later changes or deletes Course content.

## Consequences

- Reports separate revision histories instead of combining scores across incompatible content.
- Deleted Lesson titles and the minimum content needed to explain historical questions remain in immutable assessment snapshots.
- A completed learner may have an older completed revision and newer incomplete content at the same time.
- Revision creation must distinguish material learning-plan changes from presentation-only edits.
