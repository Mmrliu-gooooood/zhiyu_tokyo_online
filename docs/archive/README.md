# 历史技术资料

本目录保存已经完成、被替代或只对应某次环境的设计、实施、排查和 QA 记录。

这些文件保留原始日期、证据边界和当时路径，便于审计提交历史。它们可能描述已修复缺陷、未实施提案或已经变化的部署状态；理解当前系统时请先阅读 [现行架构](../architecture/system-overview.md) 和 [部署模式](../deployment/runtime-modes.md)，再用代码与测试复核历史结论。

- `design/`：历史视觉方案。
- `implementation-plans/`：阶段实施计划与结果。
- `investigations/`：故障排查、交接和部署方案。
- `qa/`：阶段性视觉/发布验证。
- `superpowers/`：早期规格和实现计划。
